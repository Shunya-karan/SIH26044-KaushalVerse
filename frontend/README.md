# KaushalVerse (कौशलverse)
### Digital Academia–Industry Collaboration Platform for Skill Mapping, Internships & Placement
**Smart India Hackathon (SIH) Prototype — Conceptual Demonstration**

---

## 📌 Problem Statement Overview
**Portal for Academia–Industry Collaboration for Skill Mapping, Internships and Placement**
* Associated Ministry / Initiative Context: **Ministry of Health & Family Welfare (MoHFW) / Ayushman Bharat Digital Mission (ABDM)**
* Institutional Context: Bridging the delta between university syllabi and rapid industry software engineering demands.

---

## 🚀 Key Features

### 1. Student Skills & Readiness Hub
* **Granular Skill Taxonomy**: Standardized skill catalog across Frontend, Backend, Database, Cloud/DevOps, AI/Data Science, and Digital Health Standards.
* **Skill Gap Analysis Engine**: Mathematical delta comparison between current competencies and target role requisites (Full Stack, Backend, AI/ML, Cloud, HealthTech).
* **Transparent "Explain My Score"**: Deterministic, explainable matching logic (e.g. *7 of 9 mandatory core skills matched*).
* **Personalized Learning Roadmaps**: 5-phase structured milestones with free curated resources (NPTEL, Swayam, MDN, Odin Project, AWS Skill Builder).
* **Resume Intelligence Scanner**: ATS scoring (84/100), detected skills, missing keywords, and project bullet suggestions.
* **Opportunity Discovery Feed**: Live internships and full-time jobs with real-time match compatibility percentages.
* **Multi-Step Application Flow**: 4-step verified application flow with live stage tracking timeline.

### 2. Industry / Recruiter Hub
* **Smart Candidate Matching**: Ranked applicant feed with transparent compatibility scores and exact reasons why each student matches.
* **Post Campus Opportunity**: Rich form defining mandatory vs. preferred bonus skills for automatic scoring.
* **Pipeline Management**: Candidate screening with 1-click shortlist, interview scheduling, and rejection.
* **Campus Hiring Analytics**: Conversion funnels, university applicant distribution, and hiring velocity metrics.

### 3. Institutional / Admin Command Center
* **Macro Skill Demand vs Supply Analytics**: Empirical comparison identifying curriculum deficits (e.g. Docker, CI/CD, FHIR standards).
* **Branch-wise Placement Analytics**: Departmental placement rates, CTC package brackets, and industry distribution.
* **NIRF / NAAC / AICTE Accreditation Exports**: Simulated compliance reports for academic audits.

## 💻 Tech Stack
* **Framework**: React 18 (JavaScript / JSX)
* **Build Tool**: Vite 5
* **Styling**: Tailwind CSS (with custom design tokens: Teal `#0F766E`, Emerald `#059669`, Orange `#F97316`, Violet `#7C3AED`)
* **Icons**: Lucide React
* **Charts**: Recharts (Responsive bar charts, radar charts, line charts, pie charts)
* **Routing**: React Router DOM v6
* **Notifications**: Sonner toasts
* **State Management**: React Context API (`AuthContext`, `AppContext`)

## ⏱️ 3–5 Minute Hackathon Evaluator Journey
1. **Landing Page**: View hero, live dashboard preview, demo statistics, interactive 6-step workflow, and institutional context.
2. **1-Click Demo Login**: Click **Student Demo (Aarav Sharma)** in the top bar switcher or login page.
3. **Student Dashboard**: Inspect readiness score (88%), target role match (78%), and skill gap alert.
4. **My Skills**: Check verified competencies and test the **Add Skill** modal.
5. **Skill Gap Analysis**: Toggle target roles (e.g., Full Stack vs. AI/ML), observe the Recharts Radar comparison, and read the transparent **Explain My Score** breakdown.
6. **Learning Roadmap**: Check Phase 3 In-Progress curriculum and free open learning modules.
7. **Opportunities Feed**: Click **Razorpay - Frontend Developer Intern** (92% Match).
8. **Apply Flow**: Complete the 3-step application modal and view the submission in **My Applications**.
9. **Switch to Company Demo**: Select **Company Demo (Rajesh Iyer @ Razorpay)** from the header switcher.
10. **Smart Candidate Matching**: View ranked candidates, inspect match reasons, and click **Shortlist Candidate**.
11. **Switch to Admin Demo**: Select **Institutional Admin Demo (Dr. Pradeep Sengupta)**.
12. **Placement & Skill Trends**: Inspect macro curriculum supply vs demand gaps and branch placement percentages.
